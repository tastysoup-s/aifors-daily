Benchmark validity in graph neural network scoring of metabolic reaction activity on Recon3D: detecting label leakage, memorized noise and input-invariant models

BiologyPaperbioRxivPreprint2026-09-078/10
graph-neural-networkbenchmark-validitylabel-leakagemetabolic-modeling

工作概述

问题在基于图神经网络的代谢反应活性打分中，现有基准测试方法存在系统性缺陷：活性标签通过对同一转录组矩阵设定阈值获得，而该矩阵正是模型输入，导致标签泄漏；同时，存储的标签可能由随机数生成器产生，模型可通过记忆患者不变的标签向量达到高分数。这些缺陷使基准分数和架构结论失效，需要建立可靠的评估方法。

方法本文对自有的图注意力打分器MetaGNN进行自审计，在TCGA结直肠癌(n=624)、乳腺癌(n=1,095)和肺腺癌(n=517)队列上评估。通过分析标签来源（阈值化输入或随机生成）、检查模型输入特征是否真实（发布特征张量是否为零）、比较患者间输出残差与蒙特卡洛Dropout采样离散度、以及重训练验证，来检测标签泄漏、记忆噪声和输入不变模型。

结果在TCGA-BRCA上，基于表达阈值监督的框架达到AUROC 0.9864±0.0008，但该分数可分解为：5,925个反应的标签是模型输入的确定性阈值，仅按队列平均输入排序即得AUROC 1.000；4,675个反应的标签由种子伪随机数生成器逐位复现，模型通过记忆患者不变的标签向量达到0.9291±0.0030。独立监督的队列中，存档模型从未接收患者数据，其发布特征张量全为零，独立训练模型在患者输出残差上无一致性(|r|≤0.004)。离散度比率为1.02-1.03，与无信号零模型1.02一致。重训练后AUROC降至0.5800±0.0017，低于原始表达基线0.6342±0.0058和无信息指标基线0.6085。零样本迁移在METABRIC和CPTAC-BRCA上分别仅为0.4926±0.0113和0.4986。

分析研判

该工作的核心价值在于揭示了代谢反应活性打分基准中的标签泄漏和记忆噪声问题，并提供了可复现的检测方法。其证据强度较高，因为通过重训练和零样本迁移表明先前的高性能不可持续。但需注意，该结论基于特定模型和数据集，其普遍性有待在其他方法和队列中验证。

Embedded Graph Flows for Categorical Graph Generation

ChemistryPaperarXivPaper2026-09-048/10
graph-generationmolecular-designflow-matchinggenerative-model

工作概述

问题类别化图生成需在不依赖节点顺序的前提下，为节点和边选择类型以形成连贯结构。现有方法将类别编码为固定one-hot向量，使所有类别在状态空间中保持等距，可能强加不自然的人工几何结构。本文探究能否为类别化图学习可训练的端点几何，同时处理填充、无向边和节点重标号对称性。

方法EGF将每个活动节点和无序边类别的one-hot编码映射为可学习的连续锚点向量，以高斯噪声为源，沿直线条件路径向锚点传输。使用置换等变的图transformer预测干净嵌入，并采用双分支训练：去噪分支回归干净嵌入，解码分支在t=1时对干净嵌入加高斯噪声训练分类读出头。生成时通过ODE积分和终端解码得到离散图。

结果在QM9上，EGF在四个指标上均优于DiGress和GruM：有效性99.87%（对比98.92%、99.69%），FCD 0.150（对比0.717、0.812），NSPDK-MMD 0.0019（对比0.0031、0.0036），骨架相似度0.9936（对比0.7984、0.8086）。在ZINC250k上，EGF的NSPDK-MMD最低（0.0024），但FCD 3.326高于GruM的2.276，有效性96.56%低于GruM。所有指标使用统一评估流程。

分析研判

核心价值在于将类别端点几何从固定变为可学习，并在QM9上以统一评估取得全面优势。但ZINC250k上FCD和有效性不及GruM，且仅基于单一种子训练，需更多重复实验和消融研究确认方法本身的贡献。

A physics-informed hybrid deep learning model for spatiotemporal rice disease prediction using multi-source data

BiologyPaperbioRxivPreprint2026-09-078/10

工作概述

问题水稻纹枯病的大规模准确预测对保障水稻生产至关重要，但现有预测模型常在可解释性与预测能力之间存在权衡，难以兼顾机理知识与数据驱动学习。该研究旨在构建一个融合流行病学机理与数据驱动学习的建模框架，以解决这一瓶颈。

方法提出物理信息混合门控循环单元（PI-HGRU）模型，将描述病害传播动态的微分方程作为机理约束嵌入混合门控循环单元（HGRU）框架，实现流行病学过程与数据驱动学习的协同建模。采用基于滑动时间窗口的预测框架以处理病害调查数据中采样间隔不规则和序列长度不一致的问题，并进行时间窗口敏感性分析以确定合适的输入时间窗和滞后时间配置。

结果利用2000-2016年覆盖中国南方16个主要水稻产区的17年多源数据（包括田间病害观测、遥感、气象和土壤数据）进行训练和评估。PI-HGRU相比纯数据驱动的HGRU基线，平方皮尔逊相关系数（r2）提升22.8%，均方根误差（RMSE）和平均绝对误差（MAE）分别降低10.2%和18.0%。对模型中间变量的分析显示，传播率β(t)与输入时间窗内的环境条件呈现可解释的关系，提供了环境驱动因子与模型化病害传播动态之间的过程关联。

分析研判

该工作的核心价值在于验证了物理信息约束在农业病害时空预测中的增益，但定量结果仅与单一纯数据驱动基线对比，缺乏与其他物理信息或混合模型的比较，且未报告外部验证或跨区域泛化测试，因此其广泛适用性仍需更多独立证据支持。

工作概述

问题在PAW框架下，有限位移法计算电子-声子相互作用需对N原子体系进行多达6N次自洽超胞计算，对大型、低对称性及无序材料成本过高。现有哈密顿量学习方法依赖局域化基组的质量与完备性，在过渡金属、半芯态或无序合金中可能面临挑战。本文旨在识别PAW电子-声子矩阵元中最适合机器学习的自洽量，并发展加速方案。

方法提出MLLocP策略，采用FIREANN架构学习实空间网格上的自洽局域势。每个网格点视为虚拟原子，用嵌入原子密度特征描述局域环境，通过目标采样和特征多样性选择减少训练点数。模型输出局域势，位移导数由PHELEL有限位移法构造，其余PAW量（赝波函数、投影子等）保留在VASP/PHELEL框架内。训练采用90/10配置级划分，AdamW优化。

结果在Cu、BAs和Cu3Au上验证：局域势和位移导数与DFT高度一致，输运系数误差BAs迁移率约3.5%、Cu电导率约8%、Cu3Au电导率约11%。对32原子Cu3Au SQS，用40个采样构型（36训练/4测试）使自洽计算数从192降至约五分之一；用20或10个构型加速约10倍和20倍，电导率误差为14.3%和18.6%。电子-声子矩阵元RMSE仅几meV，Fan自能误差从亚meV到几meV。额外验证单斜碳同素异形体表明不限于立方结构。

分析研判

该工作真正的价值在于识别并验证了PAW电子-声子计算中局域势是可学习的核心自洽量，且以保守方式集成到现有VASP/PHELEL流程中。但加速效果仅在单一合金体系上验证，且未与哈密顿量学习方法在统一条件下对比，泛化性和相对优势仍需更多体系及统一基准测试。
