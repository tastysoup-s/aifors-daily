Dynamic language model representations for multi-objective reaction optimisation

ChemistryPaperarXivPaper2026-09-109/10
language-modelbayesian-optimizationreaction-optimizationhigh-throughput-experimentation

工作概述

问题多目标化学反应优化（如同时优化产率、选择性、安全性）依赖反应组分的表示方式，但现有特征化路线存在瓶颈：one-hot编码稀疏且不编码化学相似性，维度随组分数量增长；分子描述符库（如Kraken、COSMO-RS）仅覆盖已建立的化合物类别，对单齿/双齿配体、无机碱、金属添加剂等化学异质组分缺乏可迁移的共享描述符空间，且每换一个反应体系都需重新进行昂贵的特征工程。

方法提出Alice框架，用可训练的语言模型嵌入作为统一反应表示。将反应条件写成文本提示（如ligand、solvent、precursor、base等组分-取值对），经LoRA微调的语言模型编码并池化为固定长度嵌入，再通过各目标专属投影头送入独立高斯过程代理模型，整个LLM-GP架构以联合边际对数似然最大化端到端训练。嵌入在每轮贝叶斯优化迭代中动态更新，适配当前优化任务。优化循环采用qLogNParEGO采集函数和Sobol初始化，支持顺序低数据与96孔板并行高通量两种实验模式。

结果回顾性基准中，在镍催化Suzuki偶联（384实验/88,000组合）上，LLM-GP达到90%超体积阈值约需13次迭代，约为DFT描述符（约26次）和one-hot（约24次）的一半；95%阈值约24次，对比约28和约30次。钯催化Suzuki偶联上两个阈值均约65次，基线各约80次。高通量96孔板磺酰胺偶联中，LLM-GP约1.2个板迭代达到阈值，基线约2.4个。前瞻性湿实验：钯催化氰化（30,000条件设计空间）两轮192实验（<1%）找到低危害K4[Fe(CN)6]条件，>99%转化率和>99%选择性，克级94%分离产率；不对称动态动力学氢化（8,064条件）两轮192实验（约2.4%）将syn选择性从5/96提升至59/96，克级84%分离产率和99.6% ee。

分析研判

核心价值在于把“表示构建”从每次新反应体系的专家前置工作变成可端到端学习的环节，且两个前瞻性湿实验的克级产率与ee支持其实际可用性。但回顾性优势在更严格的95%阈值下明显收窄，且基线中碱和前体仍用one-hot，统一算力与描述符覆盖条件下的方法本身贡献尚需独立验证。

OmniTCR: a foundation model unifying T cell receptor recognition prediction and conditional sequence generation

BiologyPaperbioRxivPreprint2026-09-138/10
foundation-modelTCR-recognitionsequence-generationimmunology

工作概述

问题T细胞受体（TCR）识别预测与受体生成长期被分开建模，导致海量TCR序列数据与规模较小的TCR-肽-MHC关联数据相互割裂，难以共享表征。核心瓶颈在于：识别预测模型受限于配对标注数据稀缺，生成模型又难以利用未标注序列库中的信息，二者无法在统一框架下互相增强。

方法OmniTCR是一个1.13亿参数的自回归基础模型，在3.28亿条格式化人类免疫序列记录上预训练。方法通过序列类型token与互补的组分顺序设计，使模型能够从单个TCR链以及部分或完整的TCR-pMHC关联中联合学习，从而在同一自回归框架下同时支持TCR识别预测与条件序列生成。

结果在未见表位上，OmniTCR对肽-TCRβ识别的AUPRC为0.7009，对TCR-pMHC相互作用预测的AUPRC为0.8235，分别超过所评估的最强对比方法0.3396和0.3451。模型在11个独立泛癌队列中区分癌症与健康免疫组库，平均AUROC为0.9436。在内部与外部生成基准上取得最高序列恢复率，结构建模支持所选pMHC条件化CDR3β候选的合理性。

分析研判

识别预测相对最强对比方法的提升幅度较大，但对比方法集合与评测协议未在摘要中说明，提升是否来自统一预训练目标而非数据规模或任务特定调优尚不清楚；跨癌种AUROC与生成恢复率也需要独立复现来确认泛化边界。

Quantum Wavefunction Augmentation via Variational Autoencoders

ChemistryPaperarXivPaper2026-09-078/10
variational-autoencoderquantum-chemistrywavefunctiongenerative-model

工作概述

问题基于采样的量子对角化（SQD）依赖量子硬件采样得到的行列式子空间做经典对角化，但在强关联区域，真实基态存在大量权重不可忽略的行列式长尾，有限采样次数无法覆盖，经典构型恢复也无法重建从未被采样到的行列式，导致精度下降。核心瓶颈是：如何在有限采样预算下系统性地把变分行列式空间扩展到波函数的真实支撑集。

方法Q-WAVE 将每个 Slater 行列式按 Jordan-Wigner 映射为二进制占据向量，用 β-退火变分自编码器（VAE）把离散高维行列式空间映射到连续隐空间。训练数据由 SqDRIFT Krylov 电路采样的行列式与经典 CISD 行列式合并，经阈值筛选、剔除 HF 参考、按温度 T=2 的权重重采样为 10^5 条批次。VAE 用 ELBO 训练，β 从 0 线性退火到小于 1 的目标值以缓解后验坍缩。生成时采用先验采样（探索）和后验扰动（利用）两种策略，解码器输出各轨道占据概率并做 Bernoulli 采样，再对 α、β 电子数分别做后处理校正。生成的行列式经对角化筛选后回灌训练集，形成生成-对角化迭代循环。

结果在 H2O 和 N2 解离中，Q-WAVE 相对 FCI 达到亚毫哈特里精度；在 52 量子比特乙烯体系上相对 CCSD(T) 达到亚毫哈特里精度；在 60 量子比特强关联 Cr2 压力测试中，经最终微扰校正后达到化学精度。与标准 SQD 相比，在相同或更好精度下所用行列式数量减少约 2–21 倍，且差距随体系增大而扩大；在 Cr2 规模下工作基比完整行列式空间小约十个数量级。与 HI-VQE 相比，以更少行列式取得更高精度。匹配的随机基线在所有体系上均未进入化学精度窗口，变分误差从 H2O 平衡构型的 22 mHa 到 Cr2 的 256 mHa。最大 Cr2 对角化约 1.9M 行列式，量子资源固定且有限（每电路不超过 5120 shots，N=15 个 qDRIFT 块）。

分析研判

主要增益来自生成模型而非基组增长，匹配随机基线全部失败支持这一点；但 Cr2 上三种初始化种子的中心值能量彼此在一个标准差内，硬件采样是否真正贡献决定性优势尚未被单独证明，且 Cr2 需微扰校正才达化学精度，变分部分本身未达标。

ischemist/project-procrustes

ChemistryToolGitHubOpen Source2026-09-137/10
retrosynthesissynthesis-planningbenchmarkevaluation

工作概述

问题多步逆合成领域缺乏统一的评估基础设施：不同模型输出格式互不兼容（如二分图、前体映射、递归字典），需为每篇论文单独编写解析器；溶解度等指标定义各异，商业库存界定不一致；标准PaRoutes n5数据集严重偏斜（74%路线长度为3-4步），掩盖了复杂目标上的性能失败，且其库存定义产生物理上不可得的合成真值。

方法RetroCast将预测与评估解耦，提供统一格式与评估工具包。其核心为Rust实现的规范化模式，将所有路线转换为严格的schema-2 Molecule/Reaction树，并通过RDKit C++计算规范SMILES、InChIKey和分子描述符。内置适配器覆盖AiZynthFinder、Retro*、DirectMultiStep、SynPlanner、Syntheseus、ASKCOS等10余个模型，采用气隙式翻译层。评估流程为Ingest→Score→Analyze，支持自助法95%置信区间、成对锦标赛和概率排名，所有产物通过SHA256加密清单追踪。

结果RetroCast引入两个基于PaRoutes的新基准系列，通过种子稳定性分析选取子集以修正原数据集的偏斜和库存问题。Reference Series面向算法开发者，使用内部PaRoutes库存隔离搜索失败与库存可用性问题，包含ref-lin-600（600个线性路线，长度2-7各100个）、ref-cnv-400（400个收敛路线，长度2-5各100个）和ref-lng-84（84个长度8-10步的极端路线）。Market Series面向计算化学家，目标筛选为可用Buyables（30万种低于$100/g的化合物目录）求解，包含mkt-lin-500（500个线性路线）和mkt-cnv-160（160个收敛路线）。原文未披露具体模型的量化对比结果。

分析研判

该工作的核心价值在于把评估基础设施本身作为可复现的科研对象：统一格式与统计检验能减少跨论文比较中的噪声，但基准修正是否真正代表化学难度分布，仍需独立使用者在不同模型上验证其分层与库存定义的实际区分度。

Machine Learning-Guided Classification of Druggable Pockets and Phylogenetic Druggability Transfer Across the Human Kinome

MedicinePaperbioRxivPreprint2026-09-137/10
kinase-druggabilityallosteric-inhibitorsphylogenetic-transferstructural-atlas

工作概述

问题蛋白激酶是肿瘤等领域重点靶点，但约536个Manning激酶域共享保守ATP结合口袋，导致选择性难题。变构结合模式可利用单个激酶或窄亚家族特有的构象状态实现选择性，然而缺乏全激酶组范围的变构口袋结构图谱，限制了这类口袋的转化潜力。

方法构建机器学习引导的激酶结构图谱，整合11,945个激酶-抑制剂复合物。以口袋残基与配体的相互作用为特征，训练Extra Trees分类器，将复合物归入七种经典结合模式，并以药理学精度细分变构亚类。随后把分类结果与Manning激酶组系统发育树整合，检验进化邻近性是否可预测共享的变构口袋可及性。

结果结构分析显示，约303个Manning激酶域有已知抑制剂结合，占Manning激酶域的约56.5%；其中仅26%（78个激酶）被非ATP竞争性变构抑制剂靶向，表明存在大量未探索的药理学空间。将分类与Manning激酶组系统发育整合后，进化邻近性是共享变构口袋可及性的统计显著预测因子，支持“系统发育可成药性转移”作为判断激酶能否被变构抑制剂靶向的信号。

分析研判

该工作的核心价值在于把系统发育邻近性变成可检验的变构可成药性预测信号，但证据主要来自已有复合物结构的回顾性分类，尚缺独立激酶或前瞻性实验验证其转移预测的准确率。

本周判断

领域走向

跨工作共性与证据边界

Biology

生物学方向最清晰的共同变化是把表示学习与预计算资源作为独立产出：自监督蛋白质 token 表征、基因组语言模型嵌入瓶颈分析、系统发育基础 Transformer 与跨物种伪时间迁移，均试图让模型在蛋白覆盖不一致、时间标签缺失或类群分布外时仍可用。验证边界集中在单队列、单参考物种或哺乳动物训练分布内，跨平台与独立实验复现仍缺。

Medicine

Chemistry

Materials

Physics

Earth

地球方向共同关注在极端稀疏或高维条件下用结构先验替代数据密度：河网水位插补把拓扑写入位置编码、火星夜间热层用弱单调性惩罚约束垂直梯度、次季节降尺度则对比动力与扩散生成路线。三项工作均受限于单一区域、两个事件或单一观测参考，跨流域、跨季节与统一成本口径下的对比尚未建立。
